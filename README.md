# wp-designmd

Generate a spec-compliant [DESIGN.md](https://github.com/google-labs-code/design.md) from your WordPress block theme's visual identity.

## Requirements

- WordPress 7.0+
- PHP 8.0+
- Active block theme
- [WordPress Studio](https://developer.wordpress.com/studio/) (recommended for local development)

## Development setup

Clone or symlink this repository into your WordPress Studio site's `wp-content/plugins/` directory, then from the plugin root:

```bash
composer install
npm install
npm run build
```

Activate the plugin in your Studio site:

```bash
studio wp plugin activate wp-designmd
```

Or activate from **Plugins** in wp-admin.

### Development workflow

- **Watch mode:** `npm run start` — rebuilds admin assets on change
- **Production build:** `npm run build` — outputs to `build/`
- **JS tests:** `npm run test`

The admin UI lives at **Appearance → DesignMD**.

### Project structure

```
wp-designmd/
├── includes/          # PHP backend (scanner, generator, REST, linter)
├── src/               # React/TypeScript admin UI (WPDS)
├── build/             # Compiled admin assets (generated by npm run build)
├── vendor/            # Composer dependencies (generated by composer install)
├── wp-designmd.php    # Plugin bootstrap
└── readme.txt         # WordPress.org-style readme
```

## Smoke test checklist

1. `studio wp plugin activate wp-designmd`
2. **Appearance → DesignMD** loads without errors
3. **Generate** creates `uploads/wp-designmd/DESIGN.md`
4. Token preview shows theme colors
5. **Download** works
6. **Regenerate** updates the timestamp
7. Validate locally: `npx @google/design.md lint path/to/DESIGN.md`
